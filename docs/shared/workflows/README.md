# Workflows

Practical guides for contributing to any repository in the project — with or without a technical background, always with AI assistance.

## When to use each guide

| I want to... | Guide |
|---|---|
| Write a new REQ or ADR from scratch | [Authoring Guide](./authoring-guide.md) |
| Fix a typo, update a requirement, correct an ADR | [Small Fix](./small-fix.md) |
| Review a Pull Request | [Code Review](./code-review.md) |
| Use AI to help me write, update, or review content | [AI-Assisted Contribution](./ai-assisted.md) |
| Add or remove an AI skill | [Add a Skill](./add-skill.md) |
| Track progress from REQ accepted through implementation | [Issue Tracking](./issue-tracking.md) |

## Repositories

See [`architecture/scm.md`](../architecture/scm.md) under **Repositories** for the full list of repositories, their URLs, and branching rules.

## SCM rules

All branching, commit message format, PR process, and merge strategy rules live in [`architecture/scm.md`](../architecture/scm.md). These guides reference but do not duplicate those rules.

## Suggested AI tools

All guides in this folder assume you have access to **OpenCode** or **Claude Code** in your terminal. Both tools can read the repository, propose edits, run shell scripts, and create PRs via `gh`. See [AI-Assisted Contribution](./ai-assisted.md) for setup and usage patterns.
