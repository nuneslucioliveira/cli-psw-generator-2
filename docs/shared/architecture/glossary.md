## Technical Terms
| Term | Definition |
|---|---|
| **ADR** | Architecture Decision Record. A document capturing a single architectural choice, its context, and its consequences. |
| **REQ** | Requirement Document. A specification detailing problem statements, functional requirements, and acceptance criteria. |
| **BFF** | Backend for Frontend. A dedicated service that formats and routes data specifically for a single client UI. |
| **Agent** | An AI-driven process executing tasks autonomously or semi-autonomously within a constrained context window. |
| **Tool** | A discrete capability, script, or API connection exposed to an Agent (e.g., via MCP) to interact with the environment. |
